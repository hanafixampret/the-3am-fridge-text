One line a smart fridge texts its owner at 3am. Entry for the [make.fun bounty](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d).

## The line

> 3am. You stare into me like I have answers. I have condiments and regret. Pick one.

## How it works

`main.py` writes the line to `/output/entry.txt` — one line, 83 characters, inside the 1–140 character gate.

```sh
python3 main.py
cat /output/entry.txt
```
